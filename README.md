# ARGON 4.0 // Native Android App (APK)

This repository automatically compiles `Argon-GitHub-Agent.apk` via GitHub Actions.

## How to Download the APK
1. Go to the **Actions** tab -> tap the latest **Build Android APK** run -> scroll down to **Artifacts** and tap **Argon-GitHub-Agent-APK**.
2. Or go to **Releases** (`/releases`) to download `Argon-GitHub-Agent.apk` directly.
